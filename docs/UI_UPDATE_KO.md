# 이미지 UI 및 통신 화면 업데이트

## 실행

기존 설치 환경을 유지한 채 다음 명령을 사용합니다.

```bash
# Raspberry Pi 4 / LCD 9개 + 물리 버튼 9개
bash scripts/run_hardware.sh
# PC 시뮬레이터 (클릭 또는 키보드 1~9)
python -m vttt --simulate
# GPIO 없이 설정/이미지/AI 확인
python -m vttt --check
```

기본 글꼴은 `src/static/fonts/potato.ttf`입니다. `--font /경로/글꼴.ttf`로 다른 글꼴을 지정할 수 있습니다.

## 반영한 UI

- `UI예시.pdf`에 맞춰 시작 화면의 틱–택–토 순서, 메뉴의 점수/설정 위치를 정렬했습니다.
- 메인 메뉴: 2 상점 / 4 점수 / 5 플레이 / 6 설정 / 8 통신. 기존 도움말 버튼은 통신 이미지로 교체했습니다. 게임 규칙 설명은 설정에서 열 수 있습니다.
- 모드 선택: 1 돌아가기 / 2 모드 제목 / 3 현재 적용 중인 테마의 두 말 이미지와 이름 / 가운데·아래 6칸 모드 이미지. 3번을 누르면 테마를 변경할 수 있으며 복귀 시 새 테마를 즉시 반영합니다.
- 난이도: 4 초보 / 5 중수 / 6 고수 선택 → 8 확인. 7 지움으로 선택 해제.
- 가위바위보: 위 가운데 상대 선택, 가운데 행 설명, 아래 행 7 가위 / 8 바위 / 9 보 이미지. 비기면 다시 선택하고, 결정되면 선공에 맞춰 기존 게임으로 이동합니다. 같은 기기 2인 플레이에서는 1P가 선택합니다.
- 상점·테마: 1 돌아가기 / 2 상점 / 3 보유 골드, 4~6 테마 미리보기, 7 이전 / 8 구매·적용 / 9 다음. 화살표로 테마가 한 칸씩 이동합니다. 치이카와 1·2의 새 O/X 이미지를 추가했습니다. 기존 테마의 가격과 소유 기록을 유지합니다.
- 통신 선택: 1 돌아가기 / 2 통신 선택 / 3 네트워크 설정, 4 로컬 / 5 아이콘 / 6 온라인, 7·9 안내. 4·6번을 누르면 해당 화면으로 바로 이동하며 8번 확인 버튼은 제거했습니다.
- 로컬·온라인: 1 돌아가기 / 2 종류 제목 / 3 네트워크 설정, 4 방 만들기 / 5 방 찾기.
- 방 만들기: 가운데 방 번호·대기 예시, 8 비활성 게임 시작 / 9 방 번호 리셋. 방 찾기: 가운데 예시 방 번호, 8 입장 / 9 다시찾기. 입장은 안내만 표시하며 실제 게임을 열지 않습니다.
- 설정·결과·상점은 `src/static/images/settings`, `result`, `shop`의 추가 이미지와 첨부된 3×3 배치를 적용했습니다. 설정의 저장 버튼은 제거했으며 변경 시 자동 저장합니다. 5번은 설정 아이콘입니다. 도움말 제목과 페이지 번호는 8번에 표시하며 규칙 상태 칸은 제거했습니다. 상점은 선택 테마에 노란 점선 테두리를 표시하며 실제 가격·보유 골드를 표시합니다.
- 기본 상대가 2인 대국이면 선공 버튼을 회색으로 음영 처리하고 입력을 차단합니다. 새 대국·재대국·일시정지 후 다시 시작 모두 가위바위보를 거칩니다. AI용 선공 설정값은 보존합니다.
- 나인스위칭은 전환 직전 턴에 빨간 테두리와 빨간색 `이제 바뀝니다!`를 표시합니다. 안내는 시간이 지나도 유지되며 전환 또는 대국 종료 시 사라집니다.
- 전환 수를 착수하면 먼저 자신의 말로 놓인 보드를 화면 표시 후 1초 동안 보여줍니다. 이어서 모든 말이 함께 가로로 좁아졌다가 상대 말로 펼쳐지는 뒤집기 효과를 표시합니다. 연출 중에는 착수·일시정지 입력과 AI 진행을 막으며, 각 단계를 실제 LCD에 표시한 뒤 타이머를 시작합니다. 착수 자체로 승리하면 전환 연출 없이 승리 처리합니다.
- 모든 테마의 말 12개는 투명 배경 PNG를 사용합니다. 게임판·상점·결과창에서 알파 채널을 유지해 합성하며, 승리 칸의 배경색도 말 뒤로 보입니다.
- 게임 내 차례 안내와 승리 문구에는 현재 테마의 해당 말 이미지를 문구 옆에 표시합니다. 결과는 `[승리한 말 이미지] 승리!` 형태이며 `1P`·`2P` 표기를 제거했습니다. 가위바위보 전에는 위쪽·아래쪽으로 구분하고, 선공 결정 후 배정된 말 이미지로 표시합니다.
- 점수 화면은 공통 돌아가기 이미지와 3×3 구성을 사용합니다. 누적 대국·승리·패배·무승부·2인 대국·보유 골드를 큰 숫자로 표시하고 AI 상대 승률을 추가했습니다. 승률은 AI 상대 전체 대국(무승부 포함)을 기준으로 계산하며 기록이 없으면 `-`로 표시합니다. Wi-Fi는 텍스트 UI를 유지합니다.
- 게임 설명도 1번에 공통 돌아가기 이미지를 사용합니다. 위쪽은 모드 제목과 승리 목표, 가운데는 번호가 붙은 세 가지 설명, 아래쪽은 이미지 화살표와 페이지 번호로 구성했습니다. 페이지 표시는 8번을 유지하며, 규칙 상태 문구는 표시하지 않습니다.
- 그래비티의 아래줄 삭제 직전 턴에는 7·8·9번 전체를 하나로 감싸는 굵은 빨간 테두리와 `이제 지워집니다!`를 표시합니다. 실제 화면 표시 후 최소 2.5초 동안 유지하며, 그동안 선택한 첫 착수는 기억했다가 예고 종료 후 처리합니다. AI도 예고가 끝나기 전에 아래줄을 삭제하지 않습니다.
- 차례·착수 안내의 말 이미지는 최대 48px, 결과 문구의 말은 최대 72px, 결과창 오른쪽 위 승자 말은 최대 190px로 확대했습니다.
- AI 대국 승리 보상은 초보 +3 / 중수 +5 / 고수 +10 골드이며 패배는 항상 +1입니다. 난이도가 중수로 고정된 오리지널은 승리 +5입니다. 무승부와 같은 기기 2인 대국은 기존 +2를 유지합니다.

## Wi-Fi 물리 버튼 조작

통신 선택, 로컬, 온라인, 방 만들기·찾기 화면의 오른쪽 위 3번에서 열 수 있습니다.

| 위 왼쪽 | 위 가운데 | 위 오른쪽 |
|---|---|---|
| 1 돌아가기 | 2 Wi-Fi 선택 안내 | 3 다시 검색 |
| 4 공유기 A | 5 공유기 B | 6 공유기 C |
| 7 이전 목록 | 8 공유기 D | 9 다음 목록 |

실제 검색 없이 예시 네트워크 9개를 4개씩 표시합니다. 잠금/개방 상태를 표시하며, 긴 이름은 해당 LCD 안에서만 가로로 흐릅니다. 개방형 네트워크는 비밀번호 입력을 건너뜁니다.

| 위 왼쪽 | 위 가운데 | 위 오른쪽 |
|---|---|---|
| 1 취소 | 2 입력 내용·현재 대소문자 모드 | 3 연결 |
| 4 a~i | 5 j~r | 6 s~z |
| 7 대소문자 전환 | 8 숫자·기호 | 9 한 글자 삭제 |

- 문자 그룹 선택 → 9칸 중 원하는 문자 선택 → 그룹 선택 화면으로 복귀합니다. s~z의 남은 1칸은 입력하지 않습니다.
- 개별 문자 화면에서 **어느 버튼이든 1.3초 길게** 누르면 글자를 입력하지 않고 복귀합니다. 버튼을 떼어도 글자가 추가되지 않습니다.
- 숫자·기호는 6글자씩 표시하고 아래 행에 이전/그룹 복귀/다음 버튼을 배치합니다. 숫자 0~9, 모든 ASCII 문장부호와 공백을 선택할 수 있습니다. 여기서도 아무 버튼 길게 누르기로 취소합니다.
- 마지막 글자는 약 1.2초만 보여주고 `•`로 가립니다. 긴 입력은 끝 10글자를 표시하며 총 글자 수도 표시합니다. 전체 비밀번호를 보여주는 기능은 추가하지 않았습니다.
- 입력 한도는 63글자입니다. 이는 UI 입력 한도이며 실제 Wi-Fi 인증이나 비밀번호 유효성 검증을 의미하지 않습니다.
- 연결 → 연결 중 → 실패 예시로 이동합니다. 연결 중 화면의 4 성공/6 실패, 결과 화면의 6 결과 전환으로 양쪽 디자인을 확인할 수 있습니다.
- 실패해도 입력을 유지합니다. 4 비밀번호 수정 / 5 다시 연결 / 8 다른 네트워크 선택이 가능합니다. 취소·다른 네트워크·통신 화면 복귀·프로그램 종료 때 입력을 비웁니다.
- 비밀번호는 실행 중 메모리에만 두며 파일·프로필·로그에 기록하지 않습니다.

## 실제 통신 미구현

온라인 서버, 로컬 기기 검색, 방 생성·가입, Wi-Fi 장치 검색·연결, 운영체제 네트워크 설정 변경은 수행하지 않습니다. 방 번호·공유기 목록·성공·실패는 모두 UI 확인용 예시입니다. 화면에도 UI 데모와 실제 연결 없음을 명시합니다. 같은 기기에서 두 명이 번갈아 하는 기존 `2인 대국`은 기기간 로컬 통신과 별개로 유지됩니다.

문자 입력 화면에서 3번 길게 누르기는 문자 선택 취소로 사용하며 LCD 복구를 호출하지 않습니다. 다른 화면의 3번 2초 길게 누르기 LCD 복구 기능은 유지합니다. 복구 안내는 복구 직후에만 표시하여 정상 UI를 가리지 않도록 했습니다.

## 테마 말 이미지 배경 제거

2026-10-29, 내장 `image_gen` 도구의 투명 배경 편집을 사용했습니다.
기존 말 이미지를 각각 입력하여 6개 테마 × O/X 2종을 처리했습니다.
저장 위치는 `src/static/images/theme/{name}.png`입니다.

`name` 목록: `default-o`, `default-x`, `fishcat-o`, `fishcat-x`,
`squirrel-o`, `squirrel-x`, `xmas-o`, `xmas-x`, `chiikawa1-o`,
`chiikawa1-x`, `chiikawa2-o`, `chiikawa2-x`.

각 이미지에 사용한 프롬프트 (`{name}`에 해당 파일명 대입):

```text
Use case: background-extraction. Edit target: the provided {name} tic-tac-toe piece image. Remove only the plain beige/cream rectangular background and any tile border at the canvas edge, yielding a real transparent RGBA PNG cutout. Preserve the exact existing piece design, pose, shapes, colors, outlines, facial features and any existing markings/watermarks. Preserve white/cream fills INSIDE characters as opaque; make the central hole of a ring/wreath transparent. For simple O and X, retain just the colored symbol. Keep one complete piece centered with a small transparent margin, no cropping, no new elements, no text, no shadow, no checkerboard painted into the image. This is a production game asset, not a redesign. Return only this one isolated piece.
```

렌더러는 알파 채널을 보존하고, 큰 말과 안내 문구의 작은 말 모두 같은
테마 PNG를 사용합니다. 상점에서도 투명도를 유지해 합성합니다.
